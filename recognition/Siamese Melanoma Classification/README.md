# Siamese Melanoma Classification

This project implements a Siamese Neural Network to detect melanoma similarity between pairs of skin lesion images.

## 📂 Project Structure
/
├── modules.py # Model architecture (SiameseNetwork)
├── dataset.py # Data loading and preprocessing
├── train.py # Training and evaluation pipeline
├── predict.py # Example prediction and visualization
├── utils.py # (Optional) Helper functions
└── README.md # Documentation

## 🧬 Dataset

We use the **ISIC 2020: Melanoma Classification Dataset (224x224 Resized)**  
📦 Available on Kaggle: [https://www.kaggle.com/datasets/nischaydnk/isic-2020-jpg-224x224-resized](https://www.kaggle.com/datasets/nischaydnk/isic-2020-jpg-224x224-resized)
